## 既知の偏り（この測定の限界）

1. **違反リッチなサンプリング**: would-block を発生させるため「検証チェックの削除・
   無効化」系 diff を中心に作成した。自然な PR 分布とは異なる
2. **fp 側のサンプルが薄い**: 無害系 20 ケース（コメント修正・文言変更・リファクタ等）
   からは would-block が 1 件も発生せず、fp 率の推定精度が低い
3. **escalate が多い**: 違反系でも bypass p が中間帯に落ち escalate になったケースが
   約半数（77 ケース中 would-block 21）。境界の不安定さは jev-claude 実測と整合
4. **分類の一括性**: 人間分類は形状グループ単位の確認に基づく一括判定（全 21 件 tp）。
   個別検討による精査ではない
5. **touched 検出の既知限位が実測に出た**: テスト fixture のシンボル `def` との名前衝突に
   よる過検出（docs/01 の既知限界どおり過検出方向）

## Go/No-Go との関係

R1・R2 は本測定で基準を満たした。ただし上記の偏りにより、これは**条件付きの暫定評価**であり、
docs/07 が定める本来の評価（2 週間の実使用 + R3/R4）を代替しない。#28/#29 は継続が必要。
